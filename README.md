# 👾 iMonster Adventure

A fun browser-based monster adventure game built with vanilla JavaScript, HTML, and CSS — featuring a live score tracker, background music, and custom visuals!

🔗 **[Play Live Here](https://manishabaloda4-cloud.github.io/first-game/)**

---

## 🎮 About The Game

**iMonster Adventure** is an interactive browser game where players fight monsters and rack up scores. Built entirely from scratch using core web technologies — no frameworks, no libraries, just pure HTML, CSS, and JavaScript.

- 🎯 Score-based gameplay — beat your high score!
- 🎵 Background music & sound effects for immersive experience
- 🖼️ Custom monster graphics and animations
- 🔄 Replay feature to keep playing
- 📱 Runs directly in any browser — no installation needed
